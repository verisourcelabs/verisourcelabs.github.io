CAC Co-Pilot for certified coders

Clinical notes are rich. Coding workflows are not. Verisource Labs builds CAC Co-Pilot — a Cloud Run assistant that proposes ICD-10-CM / CPT codes for a credentialed coder to accept or override. NotifyLawlor is a DBA only.

Workflow
01

Read the note

Schema-bounded packets from synthetic outpatient charts. A coder reviews what the engine saw.

02

Propose codes

Triage plus NCCI / Excludes1 checks before anyone commits a code set.

03

Critic and judge

Grok API critic and Vertex agree/disagree/insufficient judge. Stubs until program acceptance.

04

Accept or override

Human in the loop. Persist the decision. No DFT / FHIR writeback in the MVP.

What we are building
In build

Coding copilot

ICD-10-CM / CPT suggestions with NCCI validation. A certified coder stays in the loop. The model does not finalize the claim.

In build

Cloud Run seat

IAP in front of a CPU service in us-east4. No local GPU on the coder path. Demo charts are synthetic.

In design

Query assist

AHIMA/ACDIS-style, non-leading documentation queries when the note is ambiguous.

Stack

Google Cloud is the runtime

CAC Co-Pilot runs on Cloud Run behind Identity-Aware Proxy. Accept / override rows persist to a store that can move to Cloud SQL or BigQuery. Real charts wait on written BAAs. Hosting an image is not Safe Harbor.

What this is not

  • Not an EHR replacement
  • Not a payer adjudication engine
  • Not a local-GPU product
  • Not DFT / FHIR writeback in MVP
Infrastructure & controls

Google Cloud

Cloud Run + IAP in us-east4. Vertex is the judge only. Grok API is the clinical critic.

Demo posture

Startup Demo is synthetic. No public page ships real patient data.

Human in the loop

Credentialed coder review (CPC / CCS and related). Assistive output, not authoritative claims.
